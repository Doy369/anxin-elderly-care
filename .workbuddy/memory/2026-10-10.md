**云服务处理**

- 文字：`#14261F` 主 / `#3D4F49` 正文 / `#55665E` 次要 / `#7A8B85` 辅助 / `#9AA8A2` 占位

- 行动色（立即预约）用绿系渐变 `linear-gradient(135deg,#22A855,#15803D)` 替代原橙色
- 取消/删除等危险操作红改中性灰绿 `#5F7168` / 边框 `#E4EAE6`

**踩坑记录（重要）**
- 用脚本按行号插入 CSS 声明时，`'  border: X;\n'` 前缀会把原声明挤到同一行，且脚本用 `body.lstrip('\n')` 时会吞掉原 body 首行 → 产生重复声明和错位。正确做法：找到 `{` 后插入 `'\n' + 声明`，**不 lstrip 原 body**，或直接做整块字符串替换
- `.svc-summary` 同时有 `border` 和 `border-bottom` 会冲突，只保留 `border-bottom`
- 修复时正则 `}\s*(?=\.)` 拆行会把 `} ` 结尾的单行紧凑规则（如 `.foo { ... }`）误伤，需配合花括号平衡 + 孤立 `}` 检测复查
- 教训：批量改样式后必须扫 3 项——花括号平衡、同行重复声明、孤立 `}`

**回归校验**：11 个文件全部替换，app.json 导航栏/tabBar 主色同步为 `#15803D`；校验 lazyCodeLoading、页面清单、事件绑定、JSON 可解析、WXSS 花括号、bigfont 绑定、12 个橙红色值零残留 → 全部通过；10 个 JS `node --check` 通过
