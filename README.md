# 安心养老 · 微信小程序

适老化家居安装 + 居家养老服务预约小程序，同时服务「老人自己用」和「子女代下单」两种场景。

## 导入方式

1. 打开微信开发者工具 → 导入项目 → 选择本目录
2. AppID 选「测试号」即可预览；正式发布时在 `project.config.json` 填入自己的 AppID
3. 无 npm 依赖，无需「构建 npm」，直接编译

## 页面

| 页面 | 说明 |
|---|---|
| 首页 | 双模式切换、常用服务快捷入口、进行中订单、改造与服务推荐 |
| 找服务 | 搜索 + 四类分类筛选（家居安装 / 上门照护 / 生活助养） |
| 服务预约 | 服务包含项、流程、预约表单（服务对象、联系人、定位、日期时段、数量、备注）、费用预估 |
| 我的订单 | 全部 / 进行中 / 已完成三态筛选 |
| 订单详情 | 进度时间线、服务记录回传、取消订单 |
| 家人档案 | 家人增删改，照护备注，下单时可直接选为服务对象 |
| 我的 | 使用模式、订单统计、超大字体开关、客服入口 |

## 适老化设计

- 正文不小于 30rpx，主操作按钮 96rpx 以上
- 高对比配色：深青 `#1A6B5A` + 强调橙 `#E8743B`
- 「超大字体」开关：字号 ×1.24、间距 ×1.15，一键切换并全局记忆
- 「我自己用 / 帮家人下单」双模式，子女代下单时服务记录同步对方
- 首页常驻客服电话，一键拨号

## 数据存储

当前使用微信本地缓存（`wx.setStorageSync`），全部读写集中在 `utils/store.js`，接口形态按云端版设计——后续接入云服务只需替换该文件实现，页面代码无需改动。

订单、家人档案、超大字体与模式选择均可在应用重启后恢复。

## 架构

```
小程序页面  →  utils/store.js  →  ┬─ utils/cloud-api.js → 云函数（login / elder / order）→ 云数据库
                                  └─ utils/local-store.js → wx.setStorageSync
```

`utils/config.js` 里填了云开发环境 ID 就走云端，没填就走本地。页面只 require `store.js`，不区分后端。

**数据层接口**：模式与超大字体同步返回（设备偏好）；订单与家人档案返回 Promise。

## 接云开发

见 `docs/一期实施清单.md`，五步：开通环境 → 填环境 ID → 建 5 个集合 → 建索引 → 上传 3 个云函数。

两个上线前必须改的开关：`utils/config.js` 的 `demoMode`、`cloudfunctions/order/index.js` 的 `DEMO_MODE`，都要改成 `false`。
