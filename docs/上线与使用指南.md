# 在微信上使用「安心养老」

当前状态：**云服务未开通，应用未注册**，因此无法发布、无法生成试用小程序二维码。本文件说明现阶段可行的方式，以及后续发布需要什么。

---

## 方式一：微信开发者工具（现在就能用）

这是当前唯一能真正在手机上跑起来的途径，且不需要开通任何服务。

### 准备

下载安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 步骤

1. 打开开发者工具 → 启动界面点「小程序」→ 导入项目
2. **目录**：选择本项目根目录（即 `app.json` 所在目录）
3. **AppID**：选「测试号」（默认的 `touristappid` 就能用，无需注册）
4. 点击「导入」，工具会自动编译

### 看效果

- **模拟器**：左侧是实时预览，右侧是调试器和控制台
- **真机预览**：工具栏点「预览」→ 用微信扫描弹出的二维码 → 手机上打开即为真机效果
- **多端调试**：工具栏「真机调试」，可在手机上直接查看日志

### 注意

- 本项目**没有 npm 依赖**，无需执行「构建 npm」，导入后直接编译
- 若界面空白，先看控制台报错；`app.json` 的 `pages` 必须与实际页面文件一一对应

### 体验要点

| 场景 | 操作 |
|---|---|
| 老人自己用 | 首页顶部切到「我自己用」 |
| 子女代下单 | 首页或「我的」切到「帮家人下单」 |
| 大字模式 | 「我的」→ 超大字体，字号放大约 24% |
| 下单流程 | 找服务 → 选服务 → 填表单 → 立即预约 → 订单详情 |
| 家人档案 | 我的 → 家人档案 → 添加，预留健康照护备注 |
| 服务记录回传 | 订单详情 → 添加一条服务记录（演示按钮） |

**数据说明**：订单、家人档案都存在手机本地（`wx.setStorageSync`），清微信缓存或换手机会丢失，且多台设备之间不互通。

## 方式二：发布为试用小程序（需先开通云服务）

### 前置条件

试用小程序的发布入口挂在**应用卡片**上，而应用卡片需要先成功开通云服务才会生成。当前这一步尚未完成，所以分享面板里没有「试用小程序」选项。

这不是界面故障——发布能力依赖应用注册，未注册就没有可发布的对象。

### 开通后的操作

1. 开通云服务（会弹出确认框，需点确认）
2. 会话中出现小程序产物卡片，点击打开预览
3. 预览面板右上角「分享 / Share」
4. 选择「试用小程序」→ 生成二维码，扫码即用，有效期 14 天

### 试用版的限制

- 只能发布试用版，**无法升级为体验版或正式版**
- 有效期 14 天
- 打算长期运营的话，一开始就该走方式三

## 方式三：绑定自己的小程序（长期运营）

### 需要先注册账号

1. 访问 https://mp.weixin.qq.com 注册小程序账号
2. 完成主体信息与邮箱验证
3. 在「开发管理 → 开发设置」中找到 **AppID**

### 填入 AppID

编辑 `project.config.json`：

```json
{
  "miniprogramRoot": "./",
  "compileType": "miniprogram",
  "appid": "你的 AppID",
  "projectname": "anxin-yanglao"
}
```

把 `touristappid` 换成你的真实 AppID。

### 发布

1. 开通云服务注册应用
2. 点击产物卡片打开预览
3. 预览面板右上角「分享 / Share」→ 选择「绑定已有小程序」
4. 扫码授权你的小程序账号，平台推送代码并提交审核
5. 先发布体验版自查，确认无误再提交正式版

### 正式版的额外要求

- 需在微信公众平台完成**小程序备案**
- 首次发布正式版会弹出隐私表单，需填写联系方式与收集的数据范围
- 正式版审核占用每周有限的提审额度
- 发布正式版会同时上线一个体验版

### 后续管理

「设置 → 数据管理 → 应用」中管理小程序的发布和云服务。

## 建议

| 目标 | 走哪条 |
|---|---|
| 自己开发调试 | 方式一 |
| 先给家里人看看 | 方式一 + 真机预览 |
| 给外人试用、收集反馈 | 开通云服务 → 方式二 |
| 长期运营、接入真实业务 | 注册账号 → 方式三 |

**关于云服务**：它是「子女远程查看父母服务记录」这个功能的技术前提。当前数据存在各自手机本地，跨设备不通；接通云服务后只需替换 `utils/store.js` 的实现，页面代码无需改动——该文件已按云端接口形态设计。
