# 配色规范 · 浅绿底 + 白卡 + 中绿

按设计稿重做后的色板。**所有文字色都经过对比度实测**，基准为 WCAG AA（正文 ≥4.5:1，大字与非文本 ≥3:1）。

## 页面与容器

| 用途 | 色值 |
|---|---|
| 页面底 | `#F4F8F2` |
| 卡片 / 弹层 | `#FFFFFF` |
| 输入框、次级块 | `#F6FAF5` |
| 浅绿强调块 | `#EAF6EB` / `#EDF7EE` |
| 分隔线 | `#F1F6F1` / `#EAF0EA` |

## 文字（附实测对比度）

| 层级 | 色值 | 白卡上 | 页面底上 | 用途 |
|---|---|---|---|---|
| 主文字 | `#1F2D22` | 14.42:1 | — | 标题、卡片标题 |
| 正文 | `#3D4A3F` | 9.33:1 | — | 段落、列表值 |
| 次要 | `#5F7165` | 5.20:1 | 4.84:1 | 说明、副标题、时间、地址 |
| 占位符 | `#74876F` | — | 3.66:1（输入底） | placeholder |
| 箭头 / 图标 | `#7A8C7E` | 3.57:1 | — | 非文本指示 |

> 早期用的 `#8A9A8C`（2.97:1）、`#9AAA9C`（2.44:1）、`#B0BEB2`（1.93:1）均已废弃，因为达不到适老化可读性要求。

## 绿色主色

| 用途 | 色值 | 对比度 |
|---|---|---|
| 主按钮渐变 | `#3D9142 → #2E7D32` | 白字 3.94 → 5.13:1 |
| 强调文字 / 标签字 | `#2E7D32` | 浅绿底 4.61:1 |
| 心情提示等正向文字 | `#4E7A54` | 白卡 4.96:1 |
| 选中态（tab、步骤条） | `#2E7D32` | 白底 5.13:1 |

## 语义色

| 用途 | 色值 |
|---|---|
| 价格 / 金额 | `#C4512E` |
| 必填星号、校验错误 | `#D9534F` |
| 暖色标签 | 底 `#FDEEE6` / 字 `#B4552A` |

## 使用约定

1. 正文 ≥30rpx，主按钮 96rpx 起，点击区 ≥88rpx
2. 新增颜色前先算对比度，正文级不得低于 4.5:1
3. 每个页面 wxss 末尾的 `.bigfont` 覆盖块要同步字号，但不改颜色
4. 深浅层级只靠 `#1F2D22` → `#3D4A3F` → `#5F7165` 三档拉开，不要再引入更浅的灰
