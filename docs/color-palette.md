# 配色规范 · 白 + 绿

全站统一为纯白底 + 绿色系，已移除所有橙、红、蓝、黄色块。

## 主色

| 用途 | 色值 |
|---|---|
| 品牌主绿（导航栏、主按钮、标题强调、选中态） | `#15803D` |
| 主绿按下态 | `#0F5C2E` |
| 渐变亮端 / 首页头部 | `#22A855` |
| 价格数字 | `#0F7A38` |

## 白与浅绿底

| 用途 | 色值 |
|---|---|
| 页面底 | `#FFFFFF` |
| 卡片底 | `#FFFFFF` + `2rpx` 描边 `#E6EFE9` |
| 输入框 / 次级块底 | `#F4F8F5` |
| 选中标签底 | `#E9F6EE` |
| 强调标签底 | `#D3EFE0` / `#D9F1E2` |
| 描边 / 分隔线 | `#E6EFE9` |

## 文字

| 用途 | 色值 |
|---|---|
| 主文字 / 标题 | `#14261F` |
| 正文 | `#3D4F49` |
| 次要说明 | `#55665E` |
| 辅助灰字 | `#7A8B85` |
| 占位符 | `#9AA8A2` |

## 状态色（全绿阶区分）

| 状态 | 底色 | 文字 |
|---|---|---|
| 待接单 | `#F1F6F2` | `#0B5F2C` |
| 已接单 | `#E9F6EE` | `#15803D` |
| 服务中 | `#D3EFE0` | `#0B5F2C` |
| 已完成 / 已取消 | `#E6EFE9` / `#F4F6F4` | `#6B7C74` |

## 行动色

「立即预约」等主行动按钮使用绿系渐变，与主色区分但仍属同一体系：

```css
background: linear-gradient(135deg, #22A855 0%, #15803D 100%);
```

## 可读性

正文 30rpx 起，深绿 `#14261F` 配白底对比充足；状态标签均已加深文字色，避免浅绿底上出现看不清的情况。
